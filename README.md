# Joiefull

Clothing catalog app with an adaptive iPhone/iPad layout, focused on accessibility (VoiceOver, Dynamic Type). Products are loaded from a remote JSON API, with likes, ratings and sharing.

**Stack:** Swift, SwiftUI, MVVM, async networking, XCTest

---

*Project completed in 2024-2025 as part of the OpenClassrooms iOS Application Developer program. Re-uploaded here from my archive.*
